## Deskripsi Project
Proyek ini adalah platform web yang menggabungkan marketplace dan pusat informasi untuk cluster. Penghuni dapat menjual produk, mengakses informasi, dan melaporkan kondisi lingkungan. Tujuannya meningkatkan kualitas cluster melalui feedback serta mendorong produktivitas ekonomi.

## Konsep Desain
- **Gaya**: Minimalis & modern
- **Warna utama**: Biru (#0E9BDF) & teal (#21A5B1) untuk kesan bersih dan terpercaya
- **Typography**: Sans-serif (clean & mudah dibaca)
- **Layout**: Grid sederhana, fokus pada kemudahan navigasi

## Struktur Halaman
- **Home**: Ringkasan info cluster & highlight produk
- **Marketplace**: Daftar produk penghuni
- **Informasi**: Pengumuman & berita dari admin
- **Laporan**: Form pelaporan kondisi cluster

## Fitur Utama
- Jual beli produk antar penghuni
- Sistem laporan & feedback
- Dashboard admin untuk monitoring
- Notifikasi informasi terbaru
